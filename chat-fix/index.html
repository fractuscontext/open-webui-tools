OpenWebUI Chat Fix & Cleaner

Fix infinite loading spinners, repair corrupted pointers & clean branches

100% private & client-side. Supports both single chat exports and full chat archive exports.

Don't know how to use?
  1. Single Chat: Open chat → ... menu → Export → JSON.
    or All Chats: Settings → Chats/Data → Export Chats.
  2. Drop the exported file into the zone below.
  3. Click repair to download the fixed JSON.
  4. In OpenWebUI, go to Settings → General → Import Chats → select the fixed file.
  5. Confirm it loads successfully, then delete the broken original.
